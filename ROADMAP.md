# ROADMAP — DuoPulse

Жирным выделены контрольные точки (gate) — до их прохождения следующий этап не начинается.
Оценки даны для одного разработчика с ИИ-ассистентом, неполный день; корректируются по факту.

| Этап | Название | Содержание | Оценка | Gate (критерий перехода) |
|---|---|---|---|---|
| **M0** | **Спайк движка** | Минимальное приложение Tauri+WebView2: открывает YouTube, играет видео 1080p/4K, проверяется DRM-контент, инжекция JS в страницу, перехват сетевых запросов | ~1 нед | **YouTube играет стабильно, скрипт инжектится, сетевые фильтры срабатывают** → Go на Tauri; иначе — переход на Electron (архитектура это допускает, см. docs/02 §7) |
| **M1** | Каркас браузера | Окно, вкладки, адресная строка с omnibox-подсказками, назад/вперёд/обновить, история, закладки, страница «Новая вкладка»; фирменный тёмный UI по гайду; спайк многоканального звука 5.1/7.1 (карточка duopulse-006); поддержка внешнего прокси SOCKS5/HTTP — быстрый доступ к заблокированным сайтам (задача 1.8, карточка CARDS/009) | 2–3 нед | Суточное использование как основного браузера автором не вызывает боли; старт < 2 с; звук 5.1/7.1 не сводится к стерео (или заведена карточка-решение) |
| **M2** | Скорость | Интеграция блокировщика (adblock-rs, списки EasyList+uBO), спящие вкладки, тёплый старт, метрики (см. docs/04) | 2 нед | Метрики M1–M3 из docs/04 достигнуты на эталонной машине; YouTube без рекламных пауз |
| **M3** | **Многоязычные субтитры v1** | YouTube-адаптер (набор 2–3 дорожек: оригинал + переводы, свободное комбинирование языков), оверлей-рендер N строк в фирменном стиле, ручная подгрузка 1–3 файлов `.srt`/`.vtt` для любого сайта (в общем наборе), сдвиг синхронизации, настройки отображения | 3–4 нед | На YouTube двойные и тройные субтитры работают стабильно на 10 случайных видео подряд; свой `.srt` накладывается на видео на любом сайте |
| **M4** | Перевод | Провайдеры перевода (см. docs/03 §7), SQLite-кэш, офлайн-деградация (без перевода — только оригинал) | 2 нед | Перевод cue-таблицы видео ≤ 30 с; повторный просмотр — из кэша без сети |
| **M5** | Полировка и сборка | Полные настройки, темы (тёмная фирменная + светлая), автообновление, установщик, бэкапы профилей, лицензия | 2 нед | Установочная сборка ставится на чистой Windows и проходит чек-лист приёмки (включая поканальный тест 5.1/7.1 и многоязычные субтитры) |
| **M6** | **VPN и доступ к заблокированным сайтам** | Встроенный WireGuard-клиент (boringtun) + локальный fail-closed-роутер, split-tunnel по доменам, kill-switch, DNS через маршрут, панель VPN (требование F-12; дизайн — docs/02 §6, задачи — docs/05 §3) | 3–4 нед | **Сценарий docs/01 §5.6: заблокированный сайт открывается без внешних VPN-приложений; kill-switch подтверждён автотестом; 1080p в туннельном маршруте — без буферизации** |
| M7 | Платформы и развитие | Адаптеры других платформ (Vimeo и др. — по карточкам с приоритетами), импорт профилей из Chrome/Edge, локализация UI | по карточкам | Каждый адаптер — отдельная карточка со своими критериями |

## Принципы приоритезации

1. **Скорость ощущается первой.** Поэтому блокировщик (M2) идёт раньше субтитров (M3):
   он даёт самый заметный эффект «быстро» на YouTube.
2. **Killer-фича как можно раньше после базового комфорта.** M3 — центральная ценность
   продукта; всё, что не нужно для M3, откладывается.
3. **Один движок — не навсегда.** Слои UI/субтитры/блокировка изолированы от слоя
   «окно+вебview» (docs/02 §1), чтобы смена Tauri↔Electron не переписывала продукт.

## Риски и меры

| Риск | Вероятность | Мера |
|---|---|---|
| Часть контента YouTube (премиум/музыка) требует Widevine DRM, поддержка DRM в WebView2 ограничена | средняя | Проверяется на M0; при проблеме — gate-переход на Electron (Chromium содержит Widevine) |
| YouTube меняет DOM/innerTube-апи, адаптер субтитров ломается | высокая | Адаптер версионируется; интеграционные тесты на записанных страницах; быстрый хотфикс-контур (docs/03 §9) |
| Блокировка рекламы на YouTube — «игра в кошки-мышки» | высокая | Использовать движок adblock-rs (синтаксис uBO) + обновляемые списки; не заниматься обходом серверными средствами |
| ToS платформ: автоматический перевод субтитров может ограничиваться | средняя | Не скачивать защищённый контент, работать только с дорожками, которые плеер сам отдаёт клиенту; перевод — клиентский, официальный API/параметры платформы |
| Один разработчик, долгие этапы | высокая | Жёсткие gate-критерии, минимальный скоуп v1 (только Windows, только тёмная тема), карточки малого размера |
| WebView2/Chromium в некоторых конфигурациях сводит звук к стерео — 5.1/7.1 не доходит до колонок | средняя | Ранняя спайк-проверка на реальной системе 5.1/7.1 (карточка duopulse-006, задача 1.7 в M1): поканальные тест-файлы + YouTube-ролики 5.1, сравнение с Chrome/Edge; при провале — исследование флагов WebView2/кодеков, решение фиксируется в ROADMAP. **08.10.2026: программно подтверждено — сведения нет** (протокол e2e/m0-results/AUDIO-PROTOCOL.md), финальное прослушивание на колонках 5.1/7.1 ожидает устройство (duopulse-006 → blocked на железе) |
| Библиотеки WireGuard в Rust (boringtun) стагнируют или не дают нужной производительности | низкая | Маршрут изолирован в `vpn/wg.rs` (docs/02 §6); план Б — системный WireGuard-сервис/Wintun или собственный handshake на `x25519-dalek`; IPC-контракт не меняется. **20.10.2026: производительность подтверждена (задача 6.2)** — boringtun 0.7 + стек smoltcp, release-замер через туннель 1,4–1,9 Гбит/с (RTT ~0,2 мс) при бюджете 100 Мбит/с; узким был не крейт, а тактование нити (тики Windows ~15,6 мс; починено wake-датаграммами и повторным poll за такт) |
| Прокси WebView2 задаётся только аргументами окружения на старте — тумблер «без перезапуска» не работает | средняя | Заложено в дизайн (docs/02 §6.1): WebView2 всегда направлен на локальный SOCKS5-роутер Core, режимы переключаются роутером без перезапуска |
| Правовые риски встроенной функции VPN | средняя | DuoPulse — только клиент: собственных серверов, «бесплатных VPN» и списков обхода нет; серверы — пользователя или его провайдера; ключи в DPAPI, дисклеймер в настройках; законность использования — ответственность пользователя |
| Видео деградирует при ходе через туннель (скорость/пинг сервера) | средняя | Split-tunnel по умолчанию: видеоплатформы — напрямую, в туннель — только заблокированные домены; порог «1080p без буферизации» — в gate M6 |
