## Задача
Из пожелания автора (комплексная проверка duopulse-065, 01.11.2026):
«можно ли поменять шрифт… субтитров» — сейчас НЕТ: из типографики
настраивается только размер (fontScalePct) и вес (дорожки), гарнитура
зашита в CSS оверлея (Inter). При этом фирменные шрифты уже в проекте
(src/theme/fonts: Inter, JetBrains Mono, Space Grotesk, сабсеты cyrillic/
latin) — предложить выбор из них + системную.

Решение (направление): поле fontFamily в SubtitlesStyle (контракт bridge,
дефолт — текущняя Inter; gen:bridge после правки), применение в
content/overlay (applyRowStyle/plate — font-family строки и плашки),
контролы: страница «Настройки → Субтитры» (select) и duo-панель
(чипы/селект рядом с размером). Живая смена — как у цветов (карточка 059),
без пере-включения набора. Дефолтные сабсеты должны покрывать кириллицу —
в списке только шрифты с готовыми сабсетами + «системный».

## Критерии готовности
- [x] SubtitlesStyle.fontFamily в контракте (дефолт Inter), gen:bridge

- [x] В списке только шрифты с кириллическими сабсетами + системный
- [x] Тесты стилей/пресетов (look-presets не ломаются: поле вне пресетов вида)
- [x] vitest зелёный; CHANGELOG дополнен
