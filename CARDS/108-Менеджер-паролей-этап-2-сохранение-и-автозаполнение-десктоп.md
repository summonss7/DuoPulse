## Задача
Этап 2 цепочки duopulse-106. Живой цикл паролей в браузере (десктоп), как Chrome:

- content-скрипт: детект сабмита формы логина (пароль + соседнее текстовое поле),
  отправка кандидата в Core (сайт origin, url, username, password).
- Бар «Сохранить пароль?» под панелью вкладок (как в Chrome): «Сохранить» /
  «Никогда для этого сайта» (denylist в хранилище) / закрыть.
- Автозаполнение: при загрузке страницы с формой логина и наличии паролей для origin —
  заполнение по клику на поле (или авто); несколько аккаунтов на сайт — выбор.
- Обновление сохранённого пароля при смене (upsert по origin+username из этапа 1).
- Инкогнито: не сохранять, не заполнять.

## Критерии готовности
- [ ] Сабмит формы логина на тестовой странице предлагает сохранить пароль; «Сохранить»
      записывает в хранилище этапа 1 (видно на экране «Пароли»)
- [ ] Повторный заход на страницу логина — пароль заполняется; смена пароля — предложение
      обновить
- [ ] «Никогда для этого сайта» — сайт больше не предлагается
- [ ] В инкогнито не предлагается и не заполняется
- [ ] e2e/ручная проверка на живых страницах описана; cargo/vitest/typecheck зелёные
- [ ] CHANGELOG, коммит + push
