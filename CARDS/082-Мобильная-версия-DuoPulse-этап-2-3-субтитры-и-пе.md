## Задача
Второй этап мобильной версии DuoPulse (каркас — duopulse-081). Суть MVP по варианту Б
(duopulse-053): на телефоне работают главные фичи DuoPulse — Duo-субтитры и перевод
видео, остальное (adblock, VPN, мульти-вкладки, спящий режим) — вне мобильной ветки,
деградация явная и задокументированная.

Переиспользовать портативное ядро (см. duopulse-053): парсеры .srt/.vtt/timedtext,
YouTube-адаптер дорожек, конвейер перевода, кэш SQLite. Десктоп-специфика (COM
WebResourceRequested, DPAPI, NSIS, метрики WebView2) — за веткой платформы.

Сделать:
- детектор видео + оверлей субтитров N строк в мобильном WebView (адаптация тача:
  жесты вместо drag-n-drop, размеры под телефон);
- панель настройки набора субтитров (языки оригинала/перевода, кегль) — мобильная
  вёрстка;
- кнопка Duo в мобильном UI, синхронизация offset/seek устойчива к сворачиванию
  приложения и ротации экрана;
- перевод офлайн-деградация как в десктопе (недоступен провайдер — честное сообщение);
- история/избранное мобильной ветки в SQLite (FTS5-поиск — если влезает без регресса).

Правила проекта (обязательны): как в шапке AGENTS.md — бэкап, тесты, сборки в builds/,
CHANGELOG с датой начала/окончания, коммит с пушем, отчёт Артёму в «Хаб ИИ». Живая
проверка на эмуляторе (adb-тапы + CDP, как novagrid-058) + на реальном YouTube-видео.

## Критерии готовности
- [ ] Duo-субтитры работают в мобильном WebView: детектор видео, оверлей N строк, синхронизация offset/seek
- [ ] Панель настройки набора (языки, кегль) — мобильная вёрстка, тач
- [ ] Перевод: конвейер десктопа в мобильной ветке, офлайн-деградация честная
- [ ] Сворачивание/ротация не рвут сессию субтитров
- [ ] Юнит-тесты переносимого ядра зелёные в мобильной конфигурации
- [ ] Живая проверка на эмулятере: видео с субтитрами, перевод, смена настроек (скриншоты)
- [ ] Десктоп-ветка без регресса (e2e)
- [ ] CHANGELOG.md дополнен (дата-время начала/окончания), коммит с пушем, README «Платформы»
