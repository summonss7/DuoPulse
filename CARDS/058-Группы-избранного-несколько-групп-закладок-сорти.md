## Задача
Из пожелания автора (карточка duopulse-057, п.5): «Я бы хотел чтобы были группы
избранных чтобы я мог сделать несколько групп между ними сортировать по типам
но сделать какие-то очень интересные и функциональные избранные».

Сейчас закладки — плоский список (SQLite `bookmarks`, url — ключ; страница
«История и закладки» + звёздочка навбара с Ctrl+D, карточка 057). Сделать:
- группы закладок (создание/переименование/удаление, вкладка может быть
  в нескольких группах или без группы);
- перемещение закладки между группами, сортировка внутри группы (вручную
  drag&drop и/или по имени/дате);
- управление на странице «История и закладки» (секция закладок), выбор группы
  при добавлении со звёздочки (мини-меню), отображение групп в omnibox-подсказках;
- миграция схемы duopulse.db без потери существующих закладок
  (все текущие — в группу по умолчанию).

Критично: не сломать экспорт/импорт профиля (settings/profile.rs переносит
закладки). Дизайн-решения по UI (гайд 06) — на усмотрение исполнителя в рамках
фирменного стиля; спорное — вопрос автору через «Хаб ИИ».

## Критерии готовности
- [ ] Схема duopulse.db поддерживает группы закладок, миграция с плоского
      списка проходит без потерь (тест)
- [ ] Группы создаются/переименовываются/удаляются на странице управления
- [ ] Закладка добавляется в выбранную группу со звёздочки навбара
- [ ] Закладки перемещаются между группами и сортируются
- [ ] Omnibox-подсказки показывают закладки (с группой)
- [ ] Экспорт/импорт профиля переносит группы (тест)
- [ ] Тесты Core (миграция, CRUD групп) и vitest чисты; сборка проходит
- [ ] CHANGELOG-запись, коммит
