## Задача
Из пожелания автора (карточка duopulse-057, п.4): «генерировать новые субтитры
на какие-то видео где нету [дорожек]». Сейчас субтитры берутся из дорожек
платформы (YouTube, включая ASR-автодорожки), файлов .srt/.vtt и облачного
перевода; на видео совсем без дорожек доступен только свой файл.

Задача — исследовательско-инженерная: выбрать и согласовать с автором путь
(обсуждение в «Хабе ИИ» до реализации):
- локальный ASR (whisper.cpp / Vosk): модель на устройстве, приватно, но вес
  и скорость на длинных видео; нужен сетевой доступ к аудиопотоку видео;
- облачный ASR (API с ключом автора, по образцу провайдеров перевода
  DeepL/Google/Libre): быстрее, но аудио уходит в облако;
- гибрид: cloud при наличии ключа, локально как фолбэк.

Дизайн-вопросы: где кнопка «сгенерировать субтитры» (duo-панель, пустое
состояние набора), прогресс/кэш (по образцу translated_tracks в SQLite),
лицензии моделей. По итогам исследования — отдельное решение автора на
архитектуру, затем реализация.

## Критерии готовности
- [ ] Исследованы варианты (локальный/облачный/гибрид): прототипы, замеры
      скорости/качества на 2–3 языках, вес/зависимости
- [ ] Решение автора зафиксировано (вопрос через «Хаб ИИ», ответ в журнале)
- [ ] Реализация по решению: генерация дорожки для видео без дорожек,
      прогресс в duo-панели, кэш повторных просмотров
- [ ] Тесты + e2e; docs/03 дополнены; CHANGELOG-запись, коммит
