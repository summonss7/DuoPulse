## Задача
Мобильная часть пожелания Артёма (карточка 099): «на телефоне чтобы я пальцем
мог перекидывать [закладки] с группы в группу». На мобильной ветке (Android,
одна вкладка-iframe) закладок нет вообще: команды history.* не зарегистрированы
в тонкой мобильной либе (src-tauri/src/lib.rs), хранилища-профиля нет, UI
закладок нет. Нужно сначала построить саму подсистему, затем — сенсорное
перекладывание.

План (по возрастанию):
1. Rust: компилировать модуль history (+ типы bridge) в мобильной либе по
   образцу subtitles (`#[cfg(any(target_os = "android", target_os = "ios"))]`),
   каталог профиля на Android (app data dir), регистрация в invoke_handler
   подмножества команд закладок (group_list/group_add/group_rename/
   group_remove/group_set_sort/bookmark_add/bookmark_remove/bookmark_update/
   bookmark_list/group_toggle_bookmark/bookmark_move). Осторожно с размером
   .so (rusqlite bundled компилируется NDK-cc — прецедентов в проекте нет,
   проверить размер и сборку).
2. UI: «Закладки» на стартовом экране мобильной ветки (группы-чипы, список,
   добавление текущего видео звёздочкой в шапке плеера).
3. Сенсорный drag&drop: long-press по закладке → палец на чип группы →
   перекладывание (та же move-семантика, что на десктопе в 099:
   из вида группы — перенос, из «Все» — добавление).
4. e2e-проверка на эмуляторе (CDP webview_devtools_remote, живой прогон
   release-APK — прецеденты duopulse-083/102).

## Критерии готовности
- [ ] На мобильной ветке есть закладки с группами: хранение в профиле приложения, добавление/удаление/переименование, группы
- [ ] Закладку можно перекладывать пальцем с группы в группу (long-press drag, move-семантика как на десктопе 099)
- [ ] Много-членства закладки в группах сохранены (модель как на десктопе)
- [ ] Сборка APK в builds/ (версия + debug/release), размер .so оценён и не разросся катастрофически
- [ ] Живой прогон на эмуляторе: добавление закладки, создание групп, перекладывание пальцем — описан в отчёте
- [ ] Коммит + push, CHANGELOG.md, README/ROADMAP при необходимости
