## Задача
Десктоп получил перевод выделенного текста (карточка duopulse-098): правый
клик → нативный пункт «Перевести выделение» → бабл с переводом и селектом
языка (gtx-эндпоинт без ключей). В мобильной версии WebView (Android) нет ни
правого клика, ни WebView2 ContextMenuRequested — нужен мобильный вход в тот
же конвейер: long-press по выделенному тексту → пункт в системном
ActionMode/контекстном меню («Перевести выделение») или своя кнопка в шапке.

Контекст: gtx-конвейер уже переносим (src-tauri/src/translate/selection.rs —
чистый Rust + HttpTransport), content-модуль бабла
content/translate-select.ts уже работает вне WebView2-специфики (кроме
window.chrome.webview-канала — на Android нужен свой транспорт сообщений
или JNI-мост, см. mobile_jni.rs / duo_mobile.rs).

## Критерии готовности
- [x] В мобильной версии есть способ перевести выделенный текст (long-press
  → пункт меню или явная кнопка), ведущий в gtx-конвейер
- [x] Бабл перевода показывает результат, язык переключается
- [x] Смок мобильной сборки проходит (живая проверка на эмуляторе)
- [x] CHANGELOG-запись, README-строка о мобильном переводе при необходимости
