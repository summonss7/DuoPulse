## Задача
docs/02 §6.2 обещал быстрое добавление split-правила прямо со страницы
ошибки («этот сайт — через VPN»), когда сайт не открылся. В задаче 6.5
(карточка 041) сделана кнопка «этот сайт — через туннель» в панели VPN
(хост активной вкладки) — сценарий docs/01 §5.6 покрыт ею; действие на
странице ошибки отложено сюда.

Суть: при неудачной навигации (ERR_*, туннель мёртв/сайт заблокирован)
показать собственную страницу ошибки с адресом, причиной и кнопкой
«этот сайт — через туннель» (vpn.add_rule для хоста + подсказка включить
туннель/split). Вероятный путь: перехват неудачной навигации в Core
(событие WebView2) → внутренняя страница duopulse://error?url=…&reason=…
(по образцу src/pages/, роутер src/main.ts).
