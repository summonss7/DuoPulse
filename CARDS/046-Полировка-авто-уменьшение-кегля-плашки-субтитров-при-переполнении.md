## Задача
Выявлено при закрытии вопросов docs/03 §10 (карточка duopulse-029, задача 3.8):
документом базовым вариантом компоновки трёх строк объявлено «авто-уменьшение
кегля при переполнении», фактически в v1 реализован более простой вариант —
перенос длинных cue внутри строки (white-space: pre-wrap) и адаптивная высота
плашки (content/overlay/overlay.ts). На типовых cue (≤ 1–2 строки текста)
выглядит правильно (shot-overlay-3rows.png), но при трёх длинных cue плашка
может закрыть заметную часть видео, особенно в полноэкранном режиме (кегль
растёт с плеером через cqw).

Задача (полировка M5, необязательная до появления дискомфорта на реальных
видео): при переполнении плашки сверх заданной доли высоты видео — плавно
уменьшать кегль строк (в пределах клампов стиля 75–300%), не теряя читаемости;
ручное колесо-размер продолжает работать поверх.

## Критерии готовности
- [x] Три длинных cue (многострочные): плашка не выходит за установленную долю высоты видео, кегль авто-уменьшен
- [x] Короткие cue: поведение и кегль не меняются (без регрессии shot-overlay-3rows.png)
- [x] Ручное колесо-размер работает поверх авто-уменьшения (клампы 75–300%)
- [x] vitest на логику расчёта масштаба; e2e/subtitles — чек переполнения
- [x] Отчёт в CHANGELOG.md, коммит + push
