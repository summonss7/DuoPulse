## Задача
Выросло из диагноза duopulse-115 («открыл ~12 вкладок — браузер завис»): утечки нет,
«зависание» — исчерпание свободной памяти машины совокупностью живых рендер-процессов
(реальная вкладка YouTube ≈ 450 МБ резидентно; 12 ≈ 5.5 ГБ при 16 ГБ RAM и параллельных
приложениях → жёсткий пейджинг → интерфейс замирает). Отягчающие факторы по коду:

1. вкладка с играющим медиа никогда не усыпляется (спящий режим 2.3 исключает все
   играющие, даже фоновое беззвучное видео);
2. popup-гварда нет — любой window.open/target=_blank любого сайта открывает
   полноценный фоновый WebView2 без ограничений (карточка 088 сделала это фичей);
3. вручную открытые вкладки материализуются сразу (lazy — только у восстановленной
   сессии).

Варианты (вопрос Артёму в «Хабе ИИ», id ai_dp115_q_20261111; можно выбрать несколько
текстом):
- 1 — фон-пауза видео: неактивная вкладка с видео БЕЗ звука ставится на паузу
  (как Chrome), дальше — обычный сон вкладки; вкладки со звуком не трогаем;
- 2 — popup-гвард: script-spawned window.open не чаще N за M секунд (напр. 3/10 с),
  сверх — блок; явные клики/средняя кнопка не ограничиваются;
- 3 — memory-saver: свободная память ниже порога → принудительный сон/выгрузка
  фоновых вкладок (ленивая материализация для возврата уже есть);
- 4 — ничего не менять, ограничение задокументировать.
