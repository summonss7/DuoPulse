- 23.11.2026 (диагноз): клик по ссылке фильма на uakinogo.io воспроизведён
  CDP-пробником debug-сборки с ВЫКЛЮЧЕННЫМ адблоком: клик по `<a href>` не
  навигирует, в консоли `Uncaught TypeError: Cannot read properties of null
  (reading 'document')` из js10.beeparentdo.com. Причина: у WebView2 нет
  popup-окон, ядро гасит NewWindowRequested (Handled=true без SetNewWindow) —
  window.open ВСЕГДА возвращает null; кликундер uakinogo (deltarockme.com
  объявляет домён → js10.beeparentdo.com/js/customs/e911500521.js) строится
  на живом окне: перехват клика (preventDefaultConfig a:true) →
  window.open('about:blank','…','width=1,height=1') → document.write → по
  focus (возврат фокуса) — location=реклама и simulateClick (elementFromPoint
  + initMouseEvent) — КОМПЕНСАЦИЯ съеденного клика. С null конвейер падает на
  document.write, компенсации нет, кука успеха не взводится — каждый клик
  мёртв («просто тупо не реагирует»). В Chrome окно живое — клик
  возвращается. С включённым адблоком deltarockme режется (duopulse-sites)
  и всё работает — жалоба с выключенным блокировщиком/ротацией домёнов.
- 23.11.2026 (фикс): content/popup-shim.ts (новый, вшит в бандл до ветки
  фреймов, топ+фреймы, не зависит от адблока): обёртка window.open —
  не-http попапы (about:blank/'' — паттерн кликундеров) получают живую
  заглушку окна (document.write/methods no-op, сеттер location → нативный
  open → фоновой вкладкой) вместо null, через 500 мс (>400-мс гварда
  кликундеров) на opener разыгрывается focus — скрипт сайта доигрывает
  компенсацию (simulateClick) и ссылка открывается; http(s)-попапы не
  тронуты (вкладка уже открыта ядром, null = «попап заблокирован», как в
