# 01 · Концепция DuoPulse

## 1. Проблема

Существующие браузеры для просмотра видео с субтитрами неудобны сразу в трёх пунктах:

1. **Либо оригинал, либо перевод.** YouTube (и другие платформы) показывает одну дорожку
   субтитров за раз. Чтобы «понимать оригинал и учить язык», нужно переключаться вручную
   или смотреть без перевода.
2. **Реклама и тяжесть.** YouTube в обычном браузере с рекламой, трекерами и десятком
   открытых вкладок заметно тормозит именно там, где нужна плавность — на видео.
3. **Субтитры только там, где дала платформа.** На многих сайтах видео идёт вообще без
   субтитров, а «приложить свой .srt к видео в браузере» не получается ничем из коробки.

## 2. Решение

**DuoPulse** — браузер, спроектированный вокруг видео:

- **двойные субтитры** на любом видео: строка оригинала + строка перевода одновременно;
- **скорость как функция**, а не побочный эффект: блокировщик на уровне движка, спящие
  вкладки, лёгкое нативное ядро;
- **свои субтитры**: перетащил `.srt`/`.vtt` — они наложились на видео на любом сайте.

## 3. Целевой пользователь

Основной пользователь — сам автор проекта (v1). Портрет: много смотрит YouTube
(образовательный и технический контент на английском), хочет одновременно читать
оригинал и перевод; ценит, когда браузер открывается мгновенно и не ест память.
v1 не оптимизируется под: мобильные платформы, синхронизацию между устройствами,
расширения сторонних магазинов.

## 4. Требования

### 4.1 Функциональные (v1)

| ID | Требование | Этап |
|---|---|---|
| F-01 | Вкладки: создание, закрытие, восстановление последней закрытой, переключение Ctrl+Tab | M1 |
| F-02 | Адресная строка: URL + поиск, подсказки из истории и закладок | M1 |
| F-03 | История и закладки: запись, поиск, удаление | M1 |
| F-04 | Блокировка рекламы/трекеров движком, отключаемая по сайту | M2 |
| F-05 | Двойные субтитры на YouTube: оригинал + перевод (дорожки самого YouTube) | M3 |
| F-06 | Ручные субтитры: `.srt`/`.vtt` поверх любого `<video>` на любом сайте | M3 |
| F-07 | Синхронизация: сдвиг субтитров ±мс, авто-подстройка к видео | M3 |
| F-08 | Внешний вид субтитров: размер, положение, две строки, цвета — в фирменном стиле | M3 |
| F-09 | Перевод дорожек: выбранный провайдер, кэш в SQLite, офлайн-деградация | M4 |
| F-10 | Настройки: тема (тёмная v1), профили, импорт/экспорт | M5 |

### 4.2 Нефункциональные

| ID | Требование | Целевое значение |
|---|---|---|
| N-01 | Холодный старт до интерактива | ≤ 1,5 с (SSD, Windows 10/11) |
| N-02 | Тёплый старт | ≤ 0,5 с |
| N-03 | Память с 5 типичными вкладками | ≤ 250 МБ поверх системного WebView2-процесса |
| N-04 | Плавность видео | 1080p60 без дропов кадров на интегрированной графике; 4K — без дропов на дискретной |
| N-05 | Отклик UI (ввод адреса, переключение вкладки) | < 16 мс на действие |
| N-06 | Энергопотребление в простое | фоновые вкладки приостановлены (CPU ≈ 0) |

### 4.3 Вне скоупа v1 (явно)

- Netflix и DRM-платформы (проверка DRM — только спайк-тест M0);
- скачивание видео/субтитров в файл — **не делаем** (ToS платформ);
- мобильные версии, macOS/Linux (архитектура не исключает, но не тестируем);
- магазин расширений; поддержка сторонних Chrome-расширений не гарантируется.

## 5. Ключевые сценарии

1. **«Учу язык»**: открыл лекцию на английском → горячая клавиша включает двойные
   субтитры (en + ru) → читаю обе строки, размер шрифта — колесом мыши по субтитрам.
2. **«Просто быстро посмотреть»**: открыл DuoPulse → сразу адресная строка → YouTube
   грузится без рекламы, видео стартует сразу; фоновые вкладки не тормозят плеер.
3. **«Видео без субтитров»**: на сайте с «голым» `<video>` перетащил свой `.srt` →
   субтитры наложились, сдвиг подстроил слайдером.
4. **«Оффлайн/без API-ключа»**: перевод недоступен → показывается оригинал и перевод
   из кэша, где он есть; остальное — вахтенным режимом без краха.

## 6. Успех v1

Считаем v1 успешным, если автор (и 2–3 приглашённых тестера) 30 дней подряд используют
DuoPulse как основной браузер для видео, и:
- двойные субтитры на YouTube работают без ручных костылей в ≥ 95% просмотров;
- никто не вернулся в прежний браузер «потому что быстрее» (замеры docs/04 подтверждаются).

## 7. Ассоциации продукта

Имя **DuoPulse** = *Duo* (двойные субтитры) + *Pulse* (скорость, «пульс» интерфейса —
неоновая подсветка активных элементов). Визуальный язык — см. [06-brand-style.md](06-brand-style.md).
