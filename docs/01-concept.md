# 01 · Концепция DuoPulse

## 1. Проблема

Существующие браузеры для просмотра видео с субтитрами неудобны сразу в четырёх пунктах:

1. **Либо оригинал, либо перевод — и никогда больше двух.** YouTube (и другие платформы)
   показывает одну дорожку субтитров за раз. Чтобы «понимать оригинал и учить язык»,
   нужно переключаться вручную или смотреть без перевода. Показать одновременно три
   языка (оригинал + два перевода, свой файл + дорожка платформы) не умеет никто.
2. **Реклама и тяжесть.** YouTube в обычном браузере с рекламой, трекерами и десятком
   открытых вкладок заметно тормозит именно там, где нужна плавность — на видео.
3. **Субтитры только там, где дала платформа.** На многих сайтах видео идёт вообще без
   субтитров, а «приложить свой .srt к видео в браузере» не получается ничем из коробки.
4. **Многоканальный звук не гарантирован.** Часть связок «браузер → Windows → колонки»
   молча сводит звук видео к стерео; владелец системы 5.1/7.1 теряет объёмный звук
   без всякого предупреждения.

## 2. Решение

**DuoPulse** — браузер, спроектированный вокруг видео:

- **многоязычные субтитры** на любом видео: две-три и больше строк одновременно —
  оригинал, переводы, свои файлы; языки комбинируются свободно (двойные «оригинал +
  перевод» — базовый случай);
- **многоканальный звук**: видео с дорожками 5.1/7.1 играет всеми каналами, без
  молчаливого сведения к стерео, когда устройство вывода Windows настроено на 5.1/7.1;
- **скорость как функция**, а не побочный эффект: блокировщик на уровне движка, спящие
  вкладки, лёгкое нативное ядро;
- **доступ к заблокированным сайтам**: встроенный VPN-клиент (WireGuard) и режим
  внешнего прокси — без отдельных VPN-приложений; через туннель идёт только трафик
  браузера, по правилам для сайтов (split-tunnel);
- **свои субтитры**: перетащил `.srt`/`.vtt` — они наложились на видео на любом сайте.

## 3. Целевой пользователь

Основной пользователь — сам автор проекта (v1). Портрет: много смотрит YouTube
(образовательный и технический контент на английском), хочет одновременно читать
оригинал и перевод; ценит, когда браузер открывается мгновенно и не ест память.
Находится в Украине: часть сайтов (в первую очередь русскоязычных) недоступна из
местной сети напрямую — для него критично открывать их из самого браузера,
без отдельного VPN-приложения (F-12).
v1 не оптимизируется под: мобильные платформы, синхронизацию между устройствами,
расширения сторонних магазинов.

## 4. Требования

### 4.1 Функциональные (v1)

| ID | Требование | Этап |
|---|---|---|
| F-01 | Вкладки: создание, закрытие, восстановление последней закрытой, переключение Ctrl+Tab | M1 |
| F-02 | Адресная строка: URL + поиск, подсказки из истории и закладок | M1 |
| F-03 | История и закладки: запись, поиск, удаление | M1 |
| F-04 | Блокировка рекламы/трекеров движком, отключаемая по сайту | M2 |
| F-05 | Многоязычные субтитры на YouTube: одновременный показ 2–3 дорожек (лимит UI v1 — 3, архитектура без верхнего предела): любые языки из доступных, оригинал + переводы платформы, свободное комбинирование | M3 |
| F-06 | Ручные субтитры: один или несколько файлов `.srt`/`.vtt` поверх любого `<video>` на любом сайте, в общем наборе с дорожками платформы | M3 |
| F-07 | Синхронизация: сдвиг субтитров ±мс, авто-подстройка к видео | M3 |
| F-08 | Внешний вид субтитров: размер, положение, до 3 строк, цвета — в фирменном стиле | M3 |
| F-09 | Перевод дорожек: выбранный провайдер, кэш в SQLite, офлайн-деградация | M4 |
| F-10 | Настройки: тема (тёмная v1), профили, импорт/экспорт | M5 |
| F-11 | Многоканальный звук: дорожки 5.1/7.1 воспроизводятся всеми каналами, без сведения к стерео (при устройстве ОС 5.1/7.1); не хуже, чем в Chrome/Edge на той же машине | M1 (спайк duopulse-006) → M5 (приёмка) |
| F-12 | Сеть без блокировок: встроенный VPN-клиент WireGuard (серверы пользователя или его провайдера VPN, импорт `.conf`), быстрый режим — внешний прокси SOCKS5/HTTP; через туннель идёт только трафик браузера; split-tunnel по доменам, kill-switch (fail-closed), DNS через туннель, приватные ключи в DPAPI | M1 (внешний прокси, задача 1.8) → M6 (полный VPN) |

### 4.2 Нефункциональные

| ID | Требование | Целевое значение |
|---|---|---|
| N-01 | Холодный старт до интерактива | ≤ 1,5 с (SSD, Windows 10/11) |
| N-02 | Тёплый старт | ≤ 0,5 с |
| N-03 | Память с 5 типичными вкладками | ≤ 250 МБ поверх системного WebView2-процесса |
| N-04 | Плавность видео | 1080p60 без дропов кадров на интегрированной графике; 4K — без дропов на дискретной |
| N-05 | Отклик UI (ввод адреса, переключение вкладки) | < 16 мс на действие |
| N-06 | Энергопотребление в простое | фоновые вкладки приостановлены (CPU ≈ 0) |

### 4.3 Вне скоупа v1 (явно)

- Netflix и DRM-платформы (проверка DRM — только спайк-тест M0);
- скачивание видео/субтитров в файл — **не делаем** (ToS платформ);
- мобильные версии, macOS/Linux (архитектура не исключает, но не тестируем);
- магазин расширений; поддержка сторонних Chrome-расширений не гарантируется;
- собственная VPN-инфраструктура (серверы/подписки DuoPulse) — не делаем: браузер —
  только клиент для серверов пользователя или его провайдера VPN; никаких встроенных
  «бесплатных VPN» и списков «что разблокировать» (правовой аспект — docs/02 §9);
- обход DRM и технических средств защиты контента — не делаем (не путать с VPN:
  F-12 меняет только сетевой маршрут, а не защиту воспроизведения).

## 5. Ключевые сценарии

1. **«Учу язык»**: открыл лекцию на английском → горячая клавиша включает двойные
   субтитры (en + ru) → читаю обе строки, размер шрифта — колесом мыши по субтитрам.
   Нужен третий язык (например, второй перевод или свой конспектный `.srt`) — добавляю
   дорожку в набор, порядок строк настраивается.
2. **«Просто быстро посмотреть»**: открыл DuoPulse → сразу адресная строка → YouTube
   грузится без рекламы, видео стартует сразу; фоновые вкладки не тормозят плеер.
3. **«Видео без субтитров»**: на сайте с «голым» `<video>` перетащил свой `.srt` →
   субтитры наложились, сдвиг подстроил слайдером.
4. **«Оффлайн/без API-ключа»**: перевод недоступен → показывается оригинал и перевод
   из кэша, где он есть; остальное — вахтенным режимом без краха.
5. **«Кино в 5.1/7.1»**: система настроена на 7.1 → видео с многоканальной дорожкой
   звучит всеми каналами (тыловые и центральный — голосом на поканальном тесте),
   как в Edge/Chrome на той же машине, без сведения в стерео.
6. **«Заблокированный сайт»**: сайт, недоступный из сети Украины напрямую, открывается
   после включения VPN в меню браузера (или уже работает в фоне в режиме split:
   заблокированные домены — через туннель, YouTube и остальное — напрямую).
   Отдельное VPN-приложение не запускается, туннель несёт только трафик браузера;
   при разрыве туннеля страницы не «протекают» в открытую (kill-switch), DNS-запросы
   не уходят мимо туннеля.

## 6. Успех v1

Считаем v1 успешным, если автор (и 2–3 приглашённых тестера) 30 дней подряд используют
DuoPulse как основной браузер для видео, и:
- двойные субтитры на YouTube работают без ручных костылей в ≥ 95% просмотров;
- тройные наборы (оригинал + два перевода / свой файл) работают на видео, где
  платформа отдаёт достаточно дорожек;
- на системе автора 5.1/7.1 звук ни одного тест-видео не сводится к стерео;
- заблокированные в сети автора сайты открываются без запуска отдельных VPN-приложений,
  видео в туннельном маршруте — без буферизации 1080p (split-tunnel);
- никто не вернулся в прежний браузер «потому что быстрее» (замеры docs/04 подтверждаются).

## 7. Ассоциации продукта

Имя **DuoPulse** = *Duo* (двойные субтитры) + *Pulse* (скорость, «пульс» интерфейса —
неоновая подсветка активных элементов). Визуальный язык — см. [06-brand-style.md](06-brand-style.md).
