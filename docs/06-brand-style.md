# 06 · Фирменный стиль DuoPulse

Эталон — `Gemini_Generated_Image_x3plulx3plulx3pl.jpg` (в корне репозитория).
Палитра извлечена из эталона программно (квантование + анализ ярких пикселей);
описание композиции — по яркостной карте.

## 1. Характер бренда

**Тёмный «кибер»-минимализм с неоновым пульсом.** Глубокий сине-чёрный фон, светящиеся
лаймовые контуры и акценты, тёплые оливковые вторичные поверхности. Настроение:
«быстро, технично, живо». Ключевой приём эталона — **светящаяся рамка-пульс** по краям
— переосмыслен в UI как подсветка активных элементов и индикатор загрузки.

## 2. Палитра (токены)

| Токен | HEX | Откуда в эталоне | Использование |
|---|---|---|---|
| `--bg-base` | `#0A0E17` | самый тёмный фон эталона | фон окна, тёмные зоны |
| `--bg-surface` | `#111D2B` | основной тёмно-синий (≈22% пикселей) | панель вкладок, тулбар |
| `--bg-elevated` | `#1D282B` | светлее фон-блоки | карточки, меню, всплывающие панели |
| `--bg-warm` | `#37302A` | тёплая тёмная зона | вторичные панели, «полки» настроек |
| `--bg-warm-2` | `#555138` | тёплая средняя | ховеры вторичных элементов, разделители |
| `--accent-neon` | `#BDFE4F` | самое яркое свечение эталона | активная вкладка, фокус, прогресс-бар, перевод-строка субтитров |
| `--accent-olive` | `#96A052` | приглушённый оливковый (≈9%) | крупные заливки акцентов, иконки-указатели |
| `--text-primary` | `#F2F7EE` | — | основной текст |
| `--text-muted` | `#96A0A8` | — | подписи, плейсхолдеры |
| `--glow-neon` | `#BDFE4F` @ 32% blur 12px | свечение краёв эталона | box-shadow активных элементов |

Дополнительные сигнальные: успех `#7FE08A`, предупреждение `#F5C04E`, ошибка `#FF5D5D`
(используются только в статусах, не в декоре).

Правила сочетания: неон — только акцентами (≤ 5% площади экрана); фон всегда из
сине-чёрной группы; тёплые оливковые — только «внутренняя мебель» поверх фона.
Неон на `--bg-base` контрастен (13:1+), оливковый текст не используется — только заливки.

## 3. Свет («пульс»)

- Активная вкладка: верхняя кромка 2px `--accent-neon` + мягкое свечение
  (`box-shadow: 0 0 12px rgba(189,254,79,.32)`).
- Индикатор загрузки страницы: тонкая линия неона, ползущая по верху вкладки
  («пульсирующий» ход 1.2 с ease-in-out).
- Фокус ввода: 1px неон-контур + свечение; hover — нейтральное (`--bg-warm-2`),
  без свечения (свечение = «включено», не «под мышью»).

## 4. Типографика

| Роль | Шрифт | Правила |
|---|---|---|
| Логотип/заголовки | **Space Grotesk** (Google Fonts, OFL) | слово «DuoPulse»: `Duo` — `--text-primary`, `Pulse` — `--accent-neon` |
| UI-текст | **Inter** | 13–14px, межстрочный 1.45 |
| Числа/адреса/метрики | **JetBrains Mono** | omnibox, счётчики, метки времени |

Иерархия без засечек и курсивов; вес: 400 / 500 / 700.

## 5. Форма и компоновка

- Скругления: 8px — контролы, 12px — панели/меню.
- Радиус окна: 10px (кастомный titlebar в фирменном стиле, M1).
- Отступы: сетка 4px; базовый шаг 8px.
- Иконки: линейные 1.5px, 16/20px, цвет `--text-muted` → `--accent-neon` (активно).
- Слоистость: фон → surface → elevated; тени заменяются свечением и лёгким
  осветлением фона (тёмная тема, «плашки вместо теней»).

## 6. Субтитры (фирменный вид фичи)

- Плашка: полупрозрачный градиент `rgba(10,14,23,.78)` → прозрачный по вертикали,
  скругление 6px, `backdrop-filter: blur(2px)`.
- Строка оригинала: `#FFFFFF`, вес 500, тёмная обводка 2px для читаемости.
- Строка перевода: `--accent-neon` `#BDFE4F`, 85% размера оригинала, вес 400.
- Третья и далее строки (многоязычный набор): `#FFFFFF` с прозрачностью 75%,
  75% размера оригинала, вес 400 — приглушённые, чтобы плашка из 3 строк не
  превращалась в «стену текста».
- Макс. ширина плашки 80% ширины видео; выравнивание по центру.

## 7. Страница «Новая вкладка»

Тёмный `--bg-base`; по центру логотип с лёгкой пульсацией свечения (ambient 3 с);
ниже — omnibox-подсказка и 8 «топ-сайтов» (скруглённые плитки `--bg-surface`,
ховер — неон-кромка). Никаких внешних запросов — только локальные ресурсы.

## 8. Do / Don't

| Делаем | Не делаем |
|---|---|
| Неон — малые площади: кромки, индикаторы, перевод-строка | Заливать неоном панели и кнопки целиком |
| Один источник свечения на экране (активный элемент) | Гирлянды из светящихся элементов |
| Тёплые оливковые — только внутри панелей | Оливковый как цвет текста или ссылок |
| Текст 13–14px, контраст ≥ 7:1 для основного | Серый текст темнее `--text-muted` |
| Пульс-анимация ≤ 1.2 с, только у активных элементов | Постоянные анимации на статичном UI |

## 9. Проверка соответствия

Каждая UI-карточка (DoD docs/05 §4 п.5) сверяется с этим гайдом по чек-листу:
палитра-токены (не «похожие» цвета, а переменные из `src/theme/`), скругления,
типографика, свечение по правилам §3, субтитры по §6.
