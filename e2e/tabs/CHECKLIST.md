# Чек-лист приёмки задачи 1.2 — Таб-бар (карточка duopulse-012)

DoD из docs/05 §3: «Ручной чек-лист проходит: 5+ вкладок, переключения,
закрытие, Ctrl+Tab, Ctrl+Shift+T». Прогон автоматизирован e2e-стендом
`node e2e/tabs/run.mjs` (17/17 PASS, 12.10.2026) на реальном приложении
(Tauri 2 + WebView2, debug-сборка) через CDP: сквозовые действия идентичны
ручным (команды bridge из живого UI, клавиатурные события в живых webview).
Визуальные пункты — по скриншотам tabbar.png / tabmenu.png.

## Стиль (гайд 06)

- ✅ Палитра-токены из style.css (= §2: #0A0E17 фон окна, #111D2B панель
  вкладок, #1D282B elevated-меню, #BDFE4F неон, #96A0A8 muted) — по скриншотам.
- ✅ Активная вкладка: кромка 2px #BDFE4F + свечение 12px/32% (§3) — видно
  на tabbar.png / tabmenu.png.
- ✅ Неон ≤ 5% площади, только акценты (§8 Do): кромка/пульс/фокус.
- ✅ Скругления: вкладки 8px сверху, меню 12px, «+» 8px (§5).
- ✅ Текст 13px, сетка 4px (§4–§5). Шрифт — системный Segoe UI вместо Inter:
  подключение фирменных шрифтов (Inter/Space Grotesk/JetBrains Mono) —
  задача 1.5 «Фирменный UI-хром», там же src/theme/ (сейчас токены в style.css).
- ✅ Пульс-анимация 1.2s ease-in-out только у загружающейся вкладки (§3, §8).

## Замечания

- Восстановление (Ctrl+Shift+T) создаёт вкладку заново по URL (WebView2 не
  восстанавливает уничтоженный инстанс): id новый, позиция бара сохраняется.
- Введённые в формы страницы данные/скролл при закрытии вкладки не
  восстанавливаются — соответствует DoD 1.2 (полное восстановление сессии —
  задача 1.6).
- Первичный эмит tabs:updated может опередить подписку UI (вкладка создаётся
  в setup до загрузки UI) — таб-бар компенсирует явным tabs.list на старте.
