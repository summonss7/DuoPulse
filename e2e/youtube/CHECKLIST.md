# Чек-лист живого прогона субтитров YouTube (задача 3.8, gate M3)

DoD из docs/05 §3: «прогон зелёный, фиксация рабочих путей адаптера»; gate M3
из ROADMAP: «двойные и тройные субтитры работают стабильно на 10 случайных
видео подряд; свой .srt накладывается на видео на любом сайте».

Прогон автоматизирован стендом `node e2e/youtube/run.mjs` на живом YouTube
(сеть обязательна) — поэтому выполняется **вручную по этому чек-листу**,
а не в CI. Фикстуры player-ответов (снапшоты списков дорожек, 11 видео)
проверяются юнит-тестами адаптера в CI без сети
(`content/adapters/youtube.test.ts` → `npm test`,
`.github/workflows/ci.yml`, docs/03 §9).

## Как запускать

1. Освободить машину: закрыть запущенный DuoPulse, убить зависшие процессы
   `duopulse.exe` / `vite` (порты 5173/9240); ведомые стенды не должны идти
   параллельно.
2. Собрать debug-exe: `cargo build` в `src-tauri` (стенд запускает его сам,
   vite dev поднимает автоматически).
3. `node e2e/youtube/run.mjs` — прогон ~15–20 мин (10 видео, паузы между
   ними снижают HTTP 429 на серийные timedtext-запросы; при отказах стенд
   делает один ретрай набора через 20 с).
4. Итог в консоли: `ALL PASS`, «видео с полным набором 2–3 дорожек: 10 из 10»,
   «рабочие пути адаптера: {"player-api":10}»; подробности — `run-last.json`.

## Gate M3 — вторая половина (свой .srt на любом сайте)

Покрывается стендом `node e2e/subtitles/run.mjs` (без внешней сети): дроп
.srt/.vtt на трёх тестовых сайтах с `<video>` (страница-стенд, плеерная
обвязка, ленивый SPA), смешивание с дорожками платформы, живой YouTube —
пункты 7–8 выше. Прогон зелёный = критерий «свой .srt накладывается на видео
на любом сайте» выполнен.

## Известная сетевая флакучесть

- HTTP 429 на серийные `tlang`-запросы (переводы) — адаптер бэкоффит 6/12/18 с,
  стенд ретраит набор один раз; если прогон краснеет только по 429 —
  перепрогнать в другой час, транспорт не менять.
- Прероллы (2–3 подряд у анонимной сессии) — стенд пережидает до 90 с;
  при таймауте всё равно пробует (как пользователь, включающий субтитры
  после рекламы).
