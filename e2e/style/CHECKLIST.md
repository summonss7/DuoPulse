Источники доказательств: [run.mjs](run.mjs) — детерминированные проверки токенов
в живом DOM (computed styles, document.fonts, behavior); пиксельная гистограмма
скриншотов — только цвета токенов; снимки — для визуальной сверки человеком.

[src/theme/fonts.css](../../src/theme/fonts.css) (локальные сабсеты, без сети).

Автопроверки прогона (12/12 PASS): стартовая вкладка и `tabs.open({})` —
`duopulse://newtab`; 8 плиток топ-сайтов из локальной истории с группировкой по
хосту; шрифты загружены локально (Space Grotesk, Inter + кириллица, JetBrains
Mono); страница не делает внешних запросов (вне localhost-семейства, включая
IPC-origin Tauri `ipc.localhost`); Enter в omnibox-подсказке навигует вкладку;
пункты главного меню работают (история открывается).

Пиксельная гистограмма снимков (System.Drawing, топ-цвета): во всех кадрах
фигурируют только цвета токенов — #0A0E17, #111D2B, #1D282B, #37302A/#555138,
#96A052, #BDFE4F, #F2F7EE, #96A0A8 + антиалиасинг-переходки; «чужих» областей
заливки неоном нет (макс. 0.18% площади на «Новой вкладке»).

Известные допущения: тумблер прокси — пилюля радиуса 10px (высота 20px,
функциональная форма тумблера); заголовки `«Новая вкладка»` у скрытой стартовой
вкладки может дублировать CDP-цели — прогон различает вкладки по разнице целей.
